       <<<<< ----------------Github Notes ----------------------->>>>>>

    1) to initialise git in any folder or directory , we have to run commmand 
      git init
      after this , on the all files a "U" symbol just appears which mean untracked
  
  2) to enable tracking we write commmand ==> git add filename1 filename2 ...
    to add every thing in the folder we run ==> git add .

  3) to remove a file from tracking we run the command ===> git rm <filename>

  4) after we perform commits , by this command ==> git commit -m "message"

  5) to see all the commits in the same working directory we run the command 
      ===> git log
  
  6) to see the which changes are made by which developer on which time we run the command ==> git blame <filename>

  7) it is good practise to commit each functionality unlike write whole code and the push 
  
  8) if our current code is buggy and we want to move to previous commit code 
   then we have two ways ===> 

   i) reseting the current node (which is head ) and pointing it towards the previous one commit id
    git reset --hard <id of commit which you want> 
    but our all the current node will be lost , so this method is not ok
  
  ii) next method is reverting the changes
   ==> git revert <id of commit>
   this command reverse the changes in the file desired file means it will remove whaterever is add and add whaterever is removed



   <--------------------adding github to vscode------------------>

 1) to link our local machine to github , all we need a link of a github repo.
   ==> git remote add <name>(you can give name whaterever you like but by convention we generally give it to "origin") <github repo link>
   to check the add repo run the command ==> git remote -v

2) to push the local branch to github branch and connect the local branch with  github(remote) branch. 

 i) git push --set-upstream origin main(branch name)
 ii) git push -u origin main(branch name)

both commands are identical 



  <---------------------important one ------------------------------------>

  => suppose we have an existing repo and we create another file and want to push in the same repo from the different machine 
=> then we will get some error like " repo contains some work , changes rejected"
=> in that case we use the command --->
  git pull origin main --allow-unrelated-histories
=> this command download the content present in the git repo the combine it with local machine repo and then push it to the github



<----------------------------branching-------------------------------->

1) to create a new branch we use the command --->
   git branch <branch name>
2) to rename the existing branch we use the command -->
   git branch -M <branch name>
3) to see the available branches we use the command -->
  git branch
4) to changes the branch we use the command --->
  git checkout <branch name>  or git switch <branch name>

5) if we push different branch's code to the repo , it will generates the error that the current branch exist on local machine but not on remote (github)
=> to solve it push the branch on the remote using the command -->
  git push -u origin main <branch name>
